# Job-shop benchmark instances

Classic public benchmark instances used in Chapter 8, in the standard
format (a line `n m`, then one line per job with `machine duration` pairs).

| Instances | Original source |
|---|---|
| ft06, ft10, ft20 | Fisher and Thompson (1963) |
| la01–la05, la16–la20 | Lawrence (1984) |
| abz5, abz6 | Adams, Balas and Zawack (1988) |
| orb01 | Applegate and Cook (1991) |

The files were taken from the JSPLIB collection
(https://github.com/tamy0612/JSPLIB), which gathers the instances
distributed through Beasley's OR-Library. `optima.json` lists the known
optimal makespans.
